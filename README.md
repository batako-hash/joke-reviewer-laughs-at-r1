A program that writes one original one-line joke about working beside AI coding agents: "I approved my agent's diff in ten seconds, then spent an hour figuring out what I'd approved." The laugh is the reversal of effort — the review takes ten seconds, the understanding takes an hour, and the order is backwards. Every developer who has rubber-stamped an agent's diff recognises it at once.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
